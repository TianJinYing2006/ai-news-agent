# 演示录屏脚本（≤ 3 分钟）

面向 KUAFUAI 实习作业（选项 A · 每日 AI 新闻助手）。
目标：用 3 分钟展示「一键启动 → 偏好配置 → 模型自主运行 → 邮件送达 → 可追溯/防重」的完整闭环。

## 录前准备（一次即可）

- 服务就绪：双击过 `start.cmd`（或正在运行），http://127.0.0.1:8000 可开；
- 数据就绪：当天已有正式简报；如需补历史氛围，另开终端跑
  `.venv\Scripts\python.exe -m news_agent.demo_seed`（演示数据，可 `--clean` 清除）；
- 打开两个窗口：浏览器（`/profile`、`/briefings`）与邮箱（收件箱）；
- **隐私**：避开邮箱地址全文与任何密钥；邮箱界面注意不暴露个人敏感信息；
- 录屏工具：Win + G（Xbox Game Bar）或 OBS；导出 720p/1080p，总时长 ≤ 3 分钟。

## 展示"模型自选工具序列"的命令（录屏 1:30 处用）

在项目根目录的 PowerShell 里粘贴执行（只读查询最近一次运行的 trace，不依赖任何凭据）：

```powershell
@'
import sqlite3, json
row = sqlite3.connect("data/news_agent.db").execute(
    "SELECT trace_json FROM agent_runs ORDER BY id DESC LIMIT 1"
).fetchone()
rows = json.loads(row[0])
tools = [e["tool"] for e in rows if "tool" in e]
stop = [e for e in rows if e.get("event") == "stop"]
print("最近一次运行：", len(tools), "次工具调用")
print(" -> ".join(tools))
print("停止原因：", stop[0]["reason"] if stop else "?")
'@ | .\.venv\Scripts\python.exe -
```

输出示例（真实运行）：
`list_dir -> bash -> ... -> fetch_rss ×6 -> search_web -> fetch_url ×6 -> write_file -> ... -> finish`。
口播：这些工具、顺序和次数全部由模型决定，代码里没有任何流程规定。

## 口播参考句（可选）

- “这不是固定流水线：调哪个工具、调用几次、什么时候停，全部由 LLM 决定——我们用受控测试钉住了这一点。”
- “邮件是不可撤销副作用，所以 `send_email` 不在工具列表里：模型只能写文件然后 `finish`。”
- “同一天重复触发不会重复发信：数据库层的原子认领 + 状态机保证。”

## 常见翻车点

- 首次依赖安装慢 → 提前跑一次 `start.cmd`，录屏时展示“服务已在运行”分支即可；
- 现场等模型生成要 2–3 分钟 → 用既有运行结果讲解，不要现场等；
- 邮件显示延迟 → 提前确认收件箱已收到，录屏时直接展示。
